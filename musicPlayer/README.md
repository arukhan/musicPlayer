# Music Player iOS
A simple iOS music player developed using Swift, UIKit, UIStackView, and AVAudioPlayer.

## Features
- 10 music tracks with album covers
- Play and Pause
- Next and Previous buttons
- Automatic playback of the next track
- Loop navigation between first and last tracks
 - Adaptive layout using Auto Layout
 
## Technologies
- Swift
- UIKit
- Storyboard
- UIStackView
- Auto Layout
- AVFoundation

## How to Run
1. Open musicPlayer.xcodeproj in Xcode.
2. Select an iPhone simulator.
3. Press Command + R to run the application.
